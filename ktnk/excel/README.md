# 作業予定マスタExcel

## ファイル

- `作業予定マスタ.xlsx`
  - マスタExcelのテンプレートです
  - マクロは未埋め込みです
- `vba/ImportSchedules.bas`
  - Webアプリからダウンロードした作業予定Excelを取り込むVBAマクロです

## 推奨運用

1. `作業予定マスタ.xlsx` をExcelで開く
2. 名前を付けて保存で `作業予定マスタ.xlsm` として保存する
3. VBAエディターを開く
4. `vba/ImportSchedules.bas` の内容を標準モジュールに貼り付ける、またはインポートする
5. `作業予定を取り込む` マクロを実行する
6. Webアプリからダウンロードした `.xlsx` または `.csv` を選択する

CSVを使う場合は、ExcelでCSVを開いて日付別シートへ手動貼り付けする運用も可能です。

## 取込仕様

- 取込元ファイルの各シートを読み込みます
- 1行目をヘッダーとして扱います
- `作業日` が入っている行だけ取り込みます
- 日付ごとのシートを自動作成します
- `取込一覧` シートにも全件を集約します
- 同じキーの行が既にある場合は上書きします
- 新規の行は末尾に追加します

重複判定キー:

```text
作業日 + 予定 + 一次会社 + 二次会社 + 次回二次会社
```

## Webアプリ側の出力列

Webアプリから出力するExcelは、以下の列順に揃えます。

```text
作業日
予定
一次会社
一次会社人数
二次会社
二次会社人数
作業エリア
作業内容
次回来場予定日
次回一次会社人数
次回二次会社
次回二次会社人数
次回作業内容
登録日時
更新日時
```
